**Anthropic launched Claude for Google Workspace in public beta on October 6, 2026. Claude now opens as a sidebar inside Google Docs, Sheets and Slides and edits the file you're working on**, so you no longer have to copy text back and forth from a chat window. It's available on all paid Claude plans, and admins can roll it out to a whole company from the Google Admin console.

## What it can do

**Google Docs:** fix a sentence or restyle a heading in place without breaking the surrounding formatting. Bigger rewrites arrive as suggestion cards you can apply or dismiss.

**Google Sheets:** write formulas, build pivot tables and charts, add tabs, and, for messy data, pull a range into Python to clean or join it and write the results back.

**Google Slides:** add slides that match your deck's existing layouts, and flag problems like overlapping elements, text running off the slide, or text that's hard to read.

Separate beta connectors also let you create or edit Google files from the Claude chat window. Access follows your existing Google sharing permissions.

## The controls that matter

By default Claude works in **"Ask before edits"** mode, so nothing changes in your file without approval. You can switch to "Accept all edits" for longer tasks. On Team and Enterprise plans, an owner has to enable the connectors before members can use them.

## Practical uses for a small business

- **Cleaning up order and lead sheets.** Deduplicate customer lists, standardise phone numbers and split addresses. This is exactly where the Python step helps.
- **Monthly reports.** Turn a sales sheet into a pivot table, a chart and a short written summary in Docs.
- **Proposals and pitch decks.** Draft in Docs, then build the matching slides without rebuilding the layout by hand.
- **Policy and product documents.** Tighten return policies, FAQs and product copy before they go on your website.

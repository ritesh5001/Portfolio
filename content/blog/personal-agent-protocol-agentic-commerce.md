**On October 6, 2026, Sierra and Meta announced the Personal Agent Protocol (PAP): an open standard for how a customer's personal AI agent signs in to a business and acts on the customer's behalf.** Walmart, Shopify and Stripe are among the founding partners. For anyone running an online store, this is the clearest signal yet that "agentic commerce", meaning AI agents shopping for people, is moving from demos to infrastructure.

## What the protocol does

- **Agents get a proper login.** An agent can start as a guest, then move to a signed-in session with read-only or write access, using OAuth, the same standard behind "Sign in with Google".
- **Businesses stay in control** of what an agent is allowed to do: browse, check an order, or actually place one.
- **It's early.** Sierra plans to publish the v0.1 specification later in October. Payments are on the roadmap, not in the first version.

Founding partners reported across coverage include Walmart, Shopify, Stripe, Rocket, Genesys and Instinct. A couple of other names appear in only one report, so treat those as unconfirmed.

## It isn't the only standard

Walmart and Shopify also take part in the Universal Commerce Protocol, co-developed by Google, and Visa's Trusted Agent Protocol covers overlapping ground. Expect a few standards to compete before one wins. You don't need to pick one today.

## What e-commerce stores should do now

You don't need to implement PAP this month. You do need a store an agent can understand:

1. **Clean product data.** Accurate titles, prices, variants, stock and specifications, plus Product structured data on every product page.
2. **Clear policies.** Shipping times, returns and COD rules in plain text, not inside images.
3. **A fast, server-rendered storefront.** Agents, like search engines, struggle with pages that are blank until JavaScript runs.
4. **A platform that will adopt these standards.** Shopify is a founding partner. On WooCommerce, expect plugins to follow, and a custom build can integrate directly.
